# 🤖 Movie & Game Recommendation Chatbot

An AI-powered conversational chatbot that helps you discover movies and games you'll actually enjoy. Just tell it what you're in the mood for, your favorite genres, or titles you've liked before, and it suggests personalized recommendations through a natural chat experience.

## Features
- Chat-based interface for natural conversation
- Recommends both movies and games
- Suggestions based on genre, mood, and user preferences
- Finds similar titles to ones you already like
- Short descriptions with each recommendation
- Quick and personalized results

## How It Works
The user chats with the bot and shares their preferences. The AI understands the request and returns relevant recommendations matched to the user's taste.

## Purpose
Built to explore AI and Natural Language Processing (NLP) in a practical, real-world use case: making entertainment discovery easier and more personal.
